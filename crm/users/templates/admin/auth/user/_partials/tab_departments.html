{% load i18n %} {% comment %} Departments tab — 2-column layout. LEFT : the user's own departments (primary + secondaries) with add/remove + promote/demote controls. RIGHT : a tree of those same departments, expanded to show teammates inside each one. The current user is marked with a "You" tag; department heads with a "Head" tag. Data model: - `UserProfile.departments` — ArrayField of codes (all assigned) - `UserProfile.main_departments` — ArrayField of codes (subset; "primary") is_primary in this template = code is in user.profile.main_departments. Multiple primaries are allowed (dep_heads of several departments). Safety rule: a primary department cannot be removed directly — user must demote it from primary first, then remove. Enforced both in the UI (button disabled with tooltip) and on the server (view rejects). {% endcomment %}

{% load i18n %} {% comment %} Departments tab — 2-column layout. LEFT : the user's own departments with add/remove + promote/demote controls. Admins additionally see grant/revoke head controls. RIGHT : a tree of those same departments, expanded to show teammates inside each one. The current user is marked with a "You" tag; department heads with a "Head" tag. Data model: - `UserProfile.departments` — ArrayField of codes (all assigned) - `UserProfile.main_departments` — ArrayField of codes (subset; "primary", i.e. user's main department, NOT headship) - `UserProfile.head_of_departments` — ArrayField of codes (subset; headship, granted explicitly by an admin) is_primary = code in main_departments. is_head = code in head_of_departments. These are orthogonal: one user can be primary in dept X without being head, or head of dept Y where it's only secondary for them. Safety rules: a primary or head department cannot be removed directly — user must demote / revoke first. Enforced in UI (button disabled) and on the server (view rejects). {% endcomment %}

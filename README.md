### Че по запуску
Чтобы запустить сайт надо:
   
Во первых прописать свой .env по примеру из .env.example, далее если у вас настроено окружение то просто прописать все команды по очереди.

   1.
   ```bash
   pip install -r requirements.txt
   ```
   2.
   ```bash
   python manage.py migrate
   ```
   3.
   ```bash
   python manage.py runserver
   ```
   4.
   ```bash
   python manage.py createsuperuser
   ```
Далее если все было сделано правильно, вас должно перекинуть на основную страницу, где затем надо в строке url вписать в конце /admin и залогиниться по тому логину и паролю который вы создавали в **`4.`** пункте.

### Дополнительно касательно удобства в просмотре кода, в requirements.txt предустановлен 'black', использует эти команды перед тем как что либо пушить к себе ветку либо в другую ветку.

1.
```bash
isort .
```

2. 
```bash
black .
```

И тогда все у вас будет прекрасно в жизни.

### Перемещение сайтом

В системе существует пока что два основных url под домена, первый это `admin`, второй `zetom`.

По `zetom` под домену, вы можете заходить и тестить фичи, сейчас там есть только фича через которую отправляютя smtp запросы на почту.
> дабы перейти на нее, впишите /zetom/email

Для того чтобы смотреть на имейлы у вас есть две опции, либо вы это делаете подключаясь к tailscale и переходите в браузере по ссылке которую я укажу ниже.
> mail.shalyn42k.pl

либо вы переходите в .env и ставите в DEBUG = TRUE, тогда сообщения должны писатся после отправки вам в консоли.

Доп. Касательно заполнения заявки по /zetom/email, там очень строгая валидация NIP поэтому гляньте в forms.py я оставил работаюший 100% польский NIP(либо просто найдите в инете)

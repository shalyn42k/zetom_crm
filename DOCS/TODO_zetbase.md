## Порядок работ (от фундамента к UI)

1. **Company + M2M + контакты/филиалы** — разблокирует половину клиентских заметок (фокус 2).
2. **Статус-локдаун + автоматика оферта→злецение** — в существующий `status_service.py` (фокус 1).
3. **next_contact + напоминания/дедлайны** — канал уведомлений уже есть.
4. **Вложения на Wniosek + StepNote** на каждом шаге.
5. **Дашборд сотрудника + профиль клиента/фирмы**.
6. **2FA** и **импорт из Access** — параллельно, независимы.

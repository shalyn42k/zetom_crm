# План проверки: первый релиз на `test` + связка с сайтом клиента

Дата: 2026-11-24. Релиз: PR #165 (`develop` → `test`), после #164.

Сайт клиента: https://zetomkatowice.eu — WordPress + Divi, только польский.
Форма «Kontakt» (`et_pb_contact_form`, поля: imię, nazwisko, telefon, e-mail,
nazwa firmy, wiadomość + капча «1 + 5 =») сейчас **только шлёт письмо**,
в CRM ничего не попадает. Загрузки файлов на сайте нет.

## Связка сайта с CRM

Хук WordPress на отправку формы Divi пересылает поля в
`POST /zetom/api/site-request/` (токен `SITE_INTAKE_TOKEN`). Письмо с сайта
остаётся запасным каналом. Настройка: [site_integration_wordpress.md](site_integration_wordpress.md).

## Что тестить

### 1. Сайт → CRM
- [ ] Заявка с сайта появляется в окне валидации, источник «Site», все поля на месте, польские буквы целые
- [ ] Сотрудники получают уведомление, письмо на biuro@zetom.eu тоже приходит

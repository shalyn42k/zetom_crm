# Единый визуальный язык на токенах Unfold — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Свести весь цвет проекта к одному файлу токенов поверх палитры Unfold, убрать фиолетово-серый фон полей и индиговый фокус, устранить расхождение копий палитры.

**Architecture:** Новый `static/css/tokens.css` определяет семантические роли (`--surface`, `--border`, `--text`, `--input-bg`, `--accent`) как алиасы на `--color-base-*` / `--color-primary-*`, которые Unfold уже отдаёт. Девять существующих CSS-файлов перестают хранить значения: их префиксные переменные (`--rm-*`, `--up-*`, `--vw-*`) становятся алиасами ролей, а литералы в правилах заменяются на `var(--…)`. Имена классов и разметка не трогаются.

**Tech Stack:** Django 5, django-unfold, чистый CSS с custom properties, `manage.py test` (Django `TestCase`), chrome-devtools MCP для скриншотов.

**Spec:** [docs/superpowers/specs/2026-08-25-visual-tokens-unification-design.md](../specs/2026-08-25-visual-tokens-unification-design.md)

## Global Constraints

- Тесты запускаются `python manage.py test` (Django `TestCase`, не pytest). `.venv` — активный python.
- **Тёмная тема ловится через `html.dark`**, никогда `data-theme="dark"` — Unfold ставит класс на `<html>`.
- **Имена классов и разметка не меняются.** `rm-*`, `cc-*`, `up-*`, `vw-*` остаются. Задача только про цвет и его источник.
- **Layout, отступы, типографика не трогаются.** Только цвет.
- `static/css/tokens.css` — единственное место в проекте, где разрешены hex-литералы цвета.
- `rgba(0,0,0,…)` в тенях под инвариант не попадает: это не hex.
- Многострочные комментарии в шаблонах — `{% comment %}…{% endcomment %}`, никогда `{# … #}`. Однострочный `{# … #}` допустим.
- Python-блоки, написанные ассистентом, помечаются `# claude`.
- Новых пользовательских строк нет — i18n в этом подпроекте не задействован. `.po` файлы не трогать.
- `crm/users/` — чужой модуль; его шаг выносится в отдельный PR (Task 8).

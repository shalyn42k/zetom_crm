# Как работать с создание фич и новых модулей в проекте

---

## По веткам

В проекте используется трехуровневая система веток:
1. **`main`** — Стабильный код. Сюда пушу только Я, когда проверю весь код и он будет всем правилам поддерживаться.
2. **`test`** — Ветка для интеграции и прогона автоматических тестов.
3. **`feature/название_модуля`** — Ваша рабочая ветка для конкретной задачи.

### Как начать работу над фичей:
1. Создайте свою ветку от актуального состояния проекта:
   ```bash
   git checkout -b feature/название_модуля
   ```
